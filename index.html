enrichable view on github ↗

Better exception handling, enriched. Attach multiple pieces of structured context to a single exception and let it carry that context as it travels through the application. Because "something went wrong" has never helped anyone at 3am.

enrichable / Main.java
EnrichableException e = new EnrichableException("Database", "DB-001", "Connection failed", ErrorLevel.ERROR); e.addInformation("Cache", "CACHE-004", "Cache was unavailable", ErrorLevel.WARNING); e.addInformation("Application", "APP-999", "Cannot continue", ErrorLevel.CRITICAL); // output — [ERROR-1] [ERROR] [Database:DB-001] Connection failed [ERROR-2] [WARNING] [Cache:CACHE-004] Cache was unavailable [ERROR-3] [CRITICAL] [Application:APP-999] Cannot continue

guardia view on github ↗

Lightweight annotation-based Java validation library built from scratch. Validate any object using simple annotations — no configuration, no dependencies. Extensible by design: adding a new constraint never requires touching the engine.

guardia / User.java
public class User { @NotNull @MinLength(value = 3, message = "Name is too short") private String name; @NotNull @Email private String email; @Range(min = 18, max = 100) private int age; } Guardia.of(user).validate().throwIfInvalid();

complexity view on github ↗

A sorting algorithm advisor. Give it a list and your priorities — it analyzes the data profile and tells you which sorting algorithm to use and why. Sits between "just use QuickSort" and reading research papers to sort 8 integers.

complexity / Main.java
ArrayAnalyzer<Integer> analyzer = new ArrayAnalyzer<>(); ScoringEngine engine = new ScoringEngine(); List<Integer> list = List.of(3, 1, 4, 1, 5, 9); UserPreference pref = new UserPreference(true, false, false); // speedOverMemory=true, stable=false, memConstrained=false DataProfile profile = analyzer.analyze(list); AlgorithmScore result = engine.recommend(profile, pref); System.out.println(result.getAlgorithm().getDisplayName()); System.out.println(result.getReason());
